# 织境 Story Studio

面向中文长篇小说创作的完整交互原型。它验证正文、大纲、角色、世界设定、时间线、关系拓扑、地图和多智能体审稿如何在同一个桌面工作台中协同。

## 运行

需要 Node.js 20.19 以上版本。

```bash
npm install
npm run dev
```

浏览器打开 `http://127.0.0.1:5173`。构建与测试：

```bash
npm run build:icons
npm run typecheck
npm test -- --run
npm run build
npx playwright test
```

`npm run build:icons` 会从 `../../assets/branding/source/` 的 SVG 主源重建网页和桌面平台图标。普通原型开发不需要每次运行；修改图标源文件后必须运行。

## 原型能力

- 作品库：新建、复制、删除、切换、导入 TXT/Markdown/项目 JSON。
- 小说续写：识别章节，模拟重建人物、势力、地点、关系、大纲、事实和时间线。
- 正文与场景：章节增删改、状态、锁定、字数和场景管理。
- 五级架构：全书、分卷、故事弧、章节和场景。
- 故事资产：角色戏份、人物弧、势力、地点、物品、伏笔、事实与证据。
- 可视化：多轨时间线、可拖动关系拓扑，以及支持方位示意图/文字树双视图和层级下钻的世界地图。
- 多智能体：每个角色独立配置服务商、模型、温度和说明；强制异构盲审规则。
- 模拟流程：规划、上下文、写作、四路盲审、仲裁、修订、事实提取、最终审校。
- 作者控制：接受、忽略、异构复核审稿意见；调整文风后选择仅未来、分支或全部规划。
- 版本与导出：快照、分支、安全恢复、TXT、Markdown 和完整项目 JSON。

## 数据说明

当前版本是浏览器原型，不会调用真实模型。所有智能体输出、Token 和费用均为模拟数据。作品保存在浏览器 `localStorage`；清理浏览器站点数据会删除本地项目，重要内容应先导出项目 JSON。

损坏的存储数据会备份为 `novel-studio-data-v1.corrupt.<时间戳>` 后回退到演示项目。全局错误页可以导出恢复数据或重置演示数据。

## 商业产品迁移

正式桌面产品将保留现有领域模型和界面结构，并依次替换：

1. `localStorage` → SQLite 与系统文件。
2. 模拟工作流 → 真实多模型编排器、任务队列和成本控制。
3. 浏览器壳 → Go + Wails 桌面应用；性能敏感模块按需使用 Rust。
4. 模拟 Provider → 系统钥匙串、API 连接与本地模型服务。
5. 单机项目 → 可选账号、许可证、云备份与团队协作。
